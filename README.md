----------------------매일 아침에 실행 후 작업 시작-------------------------

로컬 메인브란치로 이동 하여

git pull origin main 깃허브에서 올려진 자료를 당겨옴 (팀원간의 모든 데이터가 메은으로 들어가는 자료를 내파일에 공유하는 작업)

당겨온 파일을 내가 작업할 브란치인 jjy로 이동하여 병합 해줌 (merge)

git checkout jjy

git merge main
