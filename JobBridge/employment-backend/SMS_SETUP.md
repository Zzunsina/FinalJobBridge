# 문자 인증 설정

백엔드를 실행하는 IntelliJ 실행 설정 또는 환경변수에 다음 값을 등록합니다.

```text
COOLSMS_API_KEY=솔라피_API_KEY
COOLSMS_API_SECRET=솔라피_API_SECRET
COOLSMS_SENDER_NUMBER=솔라피에_등록한_발신번호
```

환경변수 이름은 COOLSMS 접두사를 사용하고 발송은 SOLAPI로 연결합니다.
발신번호 사전 등록과 문자 발송 잔액이 필요합니다. 실제 키는 소스·Git에 넣지 마세요.
설정하지 않아도 서버와 로그인은 실행되며, 문자 발송 요청에는 설정 필요 안내가 반환됩니다.
가입은 문자 인증이 필수이므로 설정 전 신규 가입은 완료할 수 없습니다.

문자 인증: 3분, 재전송: 60초, 오입력: 5회, 인증 완료 후 가입: 10분.
요청 IP당 10분에 5회 발송을 제한합니다. 프록시 뒤에서는 공유 IP 제한을 고려해 조정하세요.
인증 상태는 서버 메모리에 저장됩니다. 재시작하면 다시 인증해야 하며 여러 서버 운영 시 공유 저장소로 전환해야 합니다.
인증번호와 인증 토큰은 로그로 출력하지 않습니다. 테스트는 발송 게이트웨이를 모킹하며 실제 문자를 보내지 않습니다.

## 로컬 파일 사용

백엔드 폴더의 `.env.local`도 자동으로 읽습니다. `.env.example` 자체는 실행 설정으로 읽지 않습니다.
파일에 `COOLSMS_API_KEY`, `COOLSMS_API_SECRET`, `COOLSMS_SENDER_NUMBER`를 지정한 후 백엔드를 재시작하세요.
기존 이름 `COOLSMS_APIKEY`, `COOLSMS_APISECRET`, `COOLSMS_SENDERNUMBER`도 호환됩니다.
IntelliJ 환경변수에 같은 항목을 지정하면 환경변수가 파일보다 우선합니다.
