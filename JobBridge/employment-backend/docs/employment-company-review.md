# 기업 취업연계 검토

기존 DB는 `src/main/resources/db/employment-review-upgrade.sql`을 한 번 실행해야 합니다.
새 테이블만 추가하며 기존 신청·지원·이력서는 변경하지 않습니다.
또는 기존 실행 프로필에 `employment-review-setup`을 한 번 추가해 시작한 후 제거합니다.
신규 테스트 DB는 schema.sql에서 생성합니다.

기업은 자신에게 현재 배정된 취업연계만 조회·검토할 수 있습니다.
기업별 의견은 별도로 저장되며 다른 기업으로 재배정하면 이전 기업의 의견은 노출하지 않습니다.
공개 이력서 중 기본 이력서, 최근 수정 순으로 한 개를 조회합니다.
비공개 이력서, 첨부파일, 관리자 내부 메모, 구직자 전용 안내는 기업에 전달하지 않습니다.
기업의 의견은 관리자에게만 전달하며 취업연계의 최종 상태를 변경하지 않습니다.
