# JobBridge 기능 실행 점검 — 2026-11-04

로컬 http://localhost 에서 개인 user11, 기업 company1, 관리자 admin으로 브라우저 기능을 실행했다. 이 보고서는 이번 실행에서 확인한 결과이며 전체 기능 정상 보증은 아니다. 소스 코드는 수정하지 않았다.

## 재현한 문제

### 1. 기업 내부 면접 메모를 저장한 뒤 다시 조회할 수 없음
- 경로: 기업 → 지원자 상세 → 면접 등록.
- 면접 날짜·방식·장소와 함께 기업 내부 메모를 입력하고 저장한다.
- 저장 후 재접속해도 기업 화면에는 날짜·장소·지원자 안내만 표시되고 내부 메모는 표시되지 않는다.
- 테스트 지원서 41 / 면접 5에서 재현했다. 기업 API 응답에는 입력한 QA_PRIVATE 메모가 남아 있어 저장 실패가 아닌 화면 표시 누락이다.
- 개인 화면에서 내부 메모가 보이지 않는 것은 정상이며, 이번 실행에서도 노출되지 않았다.
- 관련 코드: JobBridge-Frontend/src/pages/Seeker.jsx의 Interviews (157행), JobBridge-Frontend/src/pages/Company.jsx의 공용 Interviews 사용 (313행).
- 증거: company-memo-missing.png.

### 2. 등록한 일반 지원 면접의 일정·장소 수정 기능을 화면에서 사용할 수 없음
- 같은 지원자 상세에서 면접 등록이 끝나면 일정 삭제만 표시된다.
- 날짜·시간·장소·지원자 안내·내부 메모를 수정하는 화면 동작이 없다.
- 예정 면접이 있으면 등록 폼도 숨겨져, 현재 화면에서는 삭제 후 재등록해야 한다.
- 기능 누락/사용성 문제이며 서버 장애로 분류하지 않는다.
- 관련 코드: Company.jsx 313행 이후, Seeker.jsx 157행 이후.

### 3. 공고 이미지 입력의 안내 문구가 공지 저장으로 표시됨
- 기업 → 공고 작성 → 기업 홍보 배너 이미지.
- 안내에 ‘공지 저장 시 함께 반영됩니다’라고 표시된다.
- 공고 저장 문구로 정정이 필요하다. 이전 점검 사항이 이번 실행에서도 재현됐다.

## 이번 실행에서 정상 확인한 흐름
- 개인 로그인 / 로그아웃 / 기업·관리자 계정 전환.
- 비공개 이력서 생성 → 미리보기 → 저장 → 재조회 → 학력 추가 → 수정 저장.
- 빈 학력의 학교명을 입력하지 않으면 브라우저 필수값 검사가 저장을 차단함.
- 지원 후 원본 이력서를 수정해도 제출 당시 이력서는 기존 내용을 유지함.
- 관심 공고 등록 → 관심 목록 반영 → 해제. 기존 관심 공고는 유지함.
- 진로 탐색 검사 36문항: 응답 저장 → 새로고침 후 복원 → 문항 이동 → 제출 → 결과 생성. 중립 응답은 전 영역 50점으로 표시됨.
- 기업 공고 초안 저장 → 심사 요청 → 관리자 게시 승인 → 공개 목록 표시.
- 새 가상 공고에 새 테스트 이력서로 지원 → 기업 수신 → 지원자 상세 조회.
- 새로고침 후 이미 지원한 공고에 중복 지원을 막는 안내 표시.
- 기업 지원 상태: 지원 완료 → 서류 검토 → 서류 합격 → 면접.
- 과거 면접 일시는 저장을 차단하고 미래 일시 입력을 요구함.
- 미래 면접 등록 → 개인 지원 상세에 동일 한국 시간·장소·공개 안내 표시.
- 문의 접수 → 관리자 검색 → 답변 등록 → 개인 문의 내역에 답변 완료·답변 내용 표시.
- 관리자 공고 마감 → 기업 공고 목록에 마감·종료 반영.
- 마지막 브라우저 오류·경고 로그 조회 결과 빈 목록.
